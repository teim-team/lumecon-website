# Lumecon Inc. — robots policy
# Search engines, AI assistants and well-behaved crawlers welcome.
# People increasingly research software through AI assistants; this
# site is written to be read by them. AI-readable summary: /llms.txt
#
# robots.txt has no inheritance: a crawler matches exactly one group,
# the most specific one naming it, and ignores every other group —
# including `User-agent: *`. So the two Disallow lines below are
# repeated in each group rather than stated once. A group may list
# several user-agents before one shared set of rules, which is how the
# repetition is kept to three copies instead of twenty-two.
#
# What is withheld, and why:
#   /_headers  a Netlify/Cloudflare convention GitHub Pages does not
#              read, so it ships as a plain public file. Until a
#              header-capable layer fronts the site it is a document
#              describing which protections are not yet enforced —
#              a free reconnaissance note. Keep it out of the index
#              while it is inert.
#   /404       the not-found page is not a destination.
#              The prefix also covers /404/.

User-agent: *
Allow: /
Disallow: /_headers
Disallow: /404
